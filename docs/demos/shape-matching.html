Shape matching — path vs primitive

Each shape is traced once, then serialized as an optimized path and with primitive recognition on. A shape that really is a circle, (rotated) ellipse, or rectangle collapses to one clean, editable element with far fewer nodes; anything else stays a path. Recognition is disabled in cutout mode, where a neighbor still traces the shared Bézier edge.
